## Installation 
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Lancer le jeu
```bash
python3 main.py
```

## Commandes
- Joueur 1 : Z/W (avancer), S (freiner), Q/A (gauche), D (droite)
- Joueur 2 : flèches directionnelles
